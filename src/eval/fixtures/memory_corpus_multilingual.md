# MEMORY.md (multilingual)

Synthetic corpus covering the six languages the project supports. Every entry is
invented. Content is deliberately parallel across languages so a query in one
language must not be answered by the section of another.

## Build commands (en)

Run the linter with all features before committing. The plain build command is
not enough and never has been.

## Comandos de compilacion (es)

Ejecuta el analizador estatico con todas las funciones antes de confirmar los
cambios. El comando de compilacion simple no basta.

## Comandos de compilacao (pt)

Execute o analisador estatico com todas as funcionalidades antes de confirmar as
alteracoes. O comando de compilacao simples nao e suficiente.

## Commandes de compilation (fr)

Lance l analyseur statique avec toutes les fonctionnalites avant de valider les
modifications. La commande de compilation simple ne suffit pas.

## Команды сборки (ru)

Запускай статический анализатор со всеми функциями перед коммитом. Простая
команда сборки недостаточна.

## Perintah build (id)

Jalankan penganalisis statis dengan semua fitur sebelum melakukan commit.
Perintah build biasa tidak cukup.

## Release tags (en)

Releases are cut from tags only. Pushing to the default branch does not start a
release pipeline.

## Etiquetas de publicacion (es)

Las publicaciones se generan solo desde etiquetas. Subir a la rama principal no
inicia ninguna publicacion.

## Etiquetas de lancamento (pt)

Os lancamentos sao gerados apenas a partir de etiquetas. Enviar para o ramo
principal nao inicia nenhum lancamento.

## Etiquettes de publication (fr)

Les publications sont produites uniquement a partir des etiquettes. Pousser sur
la branche principale ne declenche aucune publication.

## Теги релиза (ru)

Релизы собираются только из тегов. Отправка в основную ветку не запускает сборку
релиза.

## Tag rilis (id)

Rilis dibuat hanya dari tag. Mengirim ke cabang utama tidak memulai proses
rilis.

## Voice notes (en)

Send the written reply first so the thread stays searchable, then attach the
generated audio file.

## Notas de voz (es)

Envia primero la respuesta escrita para que la conversacion sea buscable, luego
adjunta el archivo de audio generado.

## Notas de voz (pt)

Envie primeiro a resposta escrita para que a conversa continue pesquisavel,
depois anexe o arquivo de audio gerado.

## Notes vocales (fr)

Envoie d abord la reponse ecrite pour que la conversation reste consultable,
puis joins le fichier audio genere.

## Голосовые сообщения (ru)

Сначала отправляй письменный ответ, чтобы переписка оставалась доступной для
поиска, затем прикладывай сгенерированный звуковой файл.

## Pesan suara (id)

Kirim balasan tertulis lebih dulu agar percakapan tetap dapat dicari, lalu
lampirkan berkas audio yang dihasilkan.
